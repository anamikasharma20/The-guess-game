# 🎯 The Guess Game

A simple Python-based number guessing game where the player tries to guess a randomly generated number between **1 and 100**.

The game provides hints after every incorrect guess, helping the player determine whether the secret number is higher or lower.

---

## 🚀 Features

* Generates a random number between **1 and 100**
* Takes user input for guesses
* Provides hints:

  *  Enter a lower number
  *  Enter a higher number
* Counts the total number of guesses
* Displays a congratulatory message when the correct number is guessed

---

## 🛠️ Technologies Used

* **Python**
* **Random Module**

---

## 💻 How It Works

1. The program generates a random number between `1` and `100`.
2. The user enters a number as their guess.
3. If the guess is higher than the generated number, the program asks the user to enter a lower number.
4. If the guess is lower, the program asks the user to enter a higher number.
5. The game continues until the user guesses the correct number.
6. The total number of guesses is displayed at the end.
